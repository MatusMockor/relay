# Agent notes (historical)

These notes are the coordination log of the agents that built the MVP core in parallel. Each note records what an agent knew at the time it wrote it, so later notes supersede earlier ones (for example `review-fixes.md` replaces the AI job methods described in `ux-fixes.md`, and `integration-core.md` closes the requests listed in `server-api.md`).

Do not treat them as current documentation. The source of truth is the code, `docs/ARCHITECTURE.md` and `CLAUDE.md`.
