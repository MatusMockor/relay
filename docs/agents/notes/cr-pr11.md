## Design note

Findings 22 and 23 ask for focus rings on the borderless inputs (composer body, AI instruction, new message fields, search box, palette and popover inputs). The prototype removes them on purpose. If keyboard focus visibility is wanted, the smallest change that keeps the look is a container rule like the existing `.chat-in:focus-within { border-color: ... }` for `.qbox`, `.cmp-ai`, `.pal-in` and `.pop-in`. That is a design call, not done here.
